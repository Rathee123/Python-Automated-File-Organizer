# 📁 Python Automated File Organizer

## 📌 Project Overview

The **Python Automated File Organizer** is a beginner-friendly Python project that automatically organizes files into separate folders based on their file extensions.

The project uses Python's built-in `os` and `shutil` modules to identify file types, create destination folders, and move files into their appropriate categories.

## 🎯 Project Objectives

- Automate file organization.
- Identify file types using file extensions.
- Create folders automatically.
- Reduce manual file management.
- Practise Python programming and file handling.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Libraries:** 
  - os – File and directory management.
  - shutil – Moving files between folders.
- **Environment:** Jupyter Notebook

## ⚙️ How It Works

1. Accesses the Desktop directory.
2. Retrieves the list of files.
3. Identifies each file's extension.
4. Categorizes files based on predefined extension groups.
5. Creates destination folders if they do not exist.
6. Moves files into their corresponding folders.
7. Displays the files inside each destination folder for verification.

## 📋 File Categories

| Category | Supported Extensions |
|---|---|
| Images | `.jpg`, `.jpeg`, `.png`, `.gif` |
| Documents | `.pdf`, `.docx`, `.txt`, `.doc` |
| Videos | `.mp4`, `.mkv`, `.avi` |
| Audio | `.mp3`, `.wav` |
| Others | All other file extensions |
